先理解這趟怎麼排

你們的住宿位置決定了節奏：前兩天不要硬衝市中心，6/11 搬到陸家嘴後才開始集中玩上海核心區。

D1 只適應抵達、入境、移動、入住已經吃掉半天，不要急著跑外灘或豫園。
D2 做選擇迪士尼整天，或新場古鎮加 Disneytown。這是整趟最大的分歧。
D3 才進城搬到陸家嘴後，豫園、城隍廟、外灘夜景就變得合理。
D4-D6 是精華法租界、成熟市區、酷老上海，三天各有性格，不混在一起。
D1 休息浦東機場、君瀾酒店、早睡 D2 彈性迪士尼或新場古鎮 D3 經典豫園、城隍廟、外灘 D4 法租界武康路、思南公館 D5 成熟市區靜安寺、愚園路 D6 酷老上海1933、多倫路 D7 回程陸家嘴到浦東機場

Day2 是整趟的關鍵選擇

這天還住君瀾，位置比較適合迪士尼或浦東近郊。不要硬衝市中心，把體力留給 6/11 之後。

Option A：上海迪士尼整天

  • 兒子想玩設施，就選這版。
  • 適合接受早出晚歸、排隊和大量步行。
  • 優先抓創極速光輪、飛越地平線、加勒比海盜、礦山車、雷鳴山漂流。
  • 晚上可留到夜間秀，也可傍晚撤到 Disneytown 吃飯。
選 A 的代價：記憶點最強，但 Day3 一定要保守。

Option B：新場古鎮＋Disneytown

  • 迪士尼不是必要，就選這版。
  • 上午慢慢出門去新場古鎮，中午吃小吃。
  • 下午回君瀾休息，避開六月悶熱與午後雨。
  • 傍晚再去 Disneytown 晚餐小逛。
選 B 的好處：舒服很多，後面市區三天品質會更穩。

D2
6/10（三）
分歧日

A 版迪士尼，B 版不迪士尼

因為還住君瀾，這天最適合浦東近郊，不適合硬衝市中心。

A版

上海迪士尼整天。早出晚歸，優先玩比較不幼齡的熱門設施。

A撤退

若不想硬撐，傍晚離園到 Disneytown 晚餐，再回君瀾。

B版

新場古鎮中午小逛，下午回飯店休息，晚上 Disneytown。

全程最大選擇看兒子意願保留體力

一句話決策

兒子想迪士尼，就 A；沒特別想，就 B。

A 版風險

很累，隔天還要換住宿，晚上不要撐到全家爆掉。

B 版風險

少了正式入園體驗；如果兒子其實想玩設施，可能會可惜。

D3
6/11（四）
進城日

君瀾 → 陸家嘴民宿 → 豫園・城隍廟 → 外灘夜景

從這天開始，才真正進入上海核心。

上午

君瀾退房，前往陸家嘴民宿，寄放行李或 check-in。

中午

陸家嘴或黃浦區簡單吃，避免把午餐變成大工程。

下午

豫園、城隍廟、九曲橋、湖心亭茶坊。

晚上

外灘夜景，看對岸陸家嘴，再回陸家嘴民宿。

經典上海搬家日外灘夜景

吃什麼

  • 佳家湯包
  • 湖心亭茶坊
  • 城隍廟小吃

太累版

Day2 若玩迪士尼，Day3 可刪豫園，只保留傍晚外灘。

雨天版

改上海博物館或室內商場，傍晚看天氣決定外灘。

D4
6/12（五）
法租界

武康大樓・武康路・思南公館

歷史感、街區氣氛、美感，適合慢慢走，不適合趕。

上午

武康大樓、武康路散步、武康庭。

中午

% Arabica 或 Luneurs，午餐和下午茶可以彈性合併。

下午

思南路、思南公館、老洋房街區散步。

晚上

阿娘麵館或附近本幫菜，之後回陸家嘴，或濱江散步。

武康大樓思南公館咖啡散步

主推版

武康大樓 → 武康路 → 思南公館 → 阿娘麵館。

加碼版

可接田子坊，但它偏商業化，不必期待太高。

太熱版

上午武康路，下午咖啡廳或商場休息，晚餐再出門。

D5
6/13（六）
成熟市區

靜安寺・南京西路・愚園路

週六避開豫園、南京東路、外灘這些人潮爆炸區。

上午

靜安寺，接靜安嘉里中心或南京西路商圈。

中午

南京西路附近吃飯，保留冷氣與休息。

下午

愚園路散步，文青小店、咖啡、老建築街區。

晚上

人和館、保羅酒家或光明邨大酒家，選一餐本幫菜即可。

靜安寺南京西路愚園路

最穩版

靜安寺 → 南京西路 → 愚園路 → 本幫菜。

購物版

靜安嘉里中心、久光百貨、南京西路，晚上短走愚園路。

雨天版

靜安寺外觀、商場、咖啡、晚餐本幫菜。

D6
6/14（日）
酷老上海

1933 老場坊・多倫路・魯迅公園

不是標準觀光客路線，但比較有個性，也比較不童趣。

上午

1933 老場坊。老屠宰場改造的設計、展覽、餐飲空間，混凝土迷宮感很強。

中午

大壺春，或附近簡單吃。

下午

多倫路文化名人街、魯迅公園周邊、萬壽齋。

晚上

看體力決定回陸家嘴，或補北外灘、外白渡橋夜景。

1933 老場坊多倫路大壺春

主推版

1933 → 多倫路 → 魯迅公園 → 萬壽齋。

夜景補完

Day3 外灘天氣不好，可這天傍晚補北外灘或外白渡橋。

刪減版

只去 1933 和大壺春，前幾天太累就回陸家嘴休息。

D7
6/15（一）
回程日

陸家嘴 → 浦東機場 → 桃園

這天不要再排正式景點，航班 13:10 起飛，早上其實很緊。

早上

民宿附近早餐，整理行李，退房。

09:30

保守版：一家三口行李多、怕趕，建議這時間左右離開陸家嘴。

10:00

稍微從容版：行李不多、叫車順利、對流程有把握才考慮。

中午

浦東機場 check-in、安檢、出境、簡單午餐，搭 BR711 回桃園。

純回程不排景點機場補貨

不要排

  • 南京路
  • 外灘
  • 豫園
  • 伴手禮專程採買

伴手禮

請前幾天完成，Day7 機場只做最後補貨。

核心提醒

回程日的勝利條件是穩穩到機場，不是再多玩一個點。

伴手禮安排

  • 不要放 Day7 專程採買。
  • Day5 可在南京西路、淮海中路、光明邨買鮮肉月餅、熟食或糕點。
  • Day6 若順路，再補沈大成、老大房、泰康食品。
  • 鮮肉月餅和熟食注意保存，不要太早買。

雨天與太熱備案

  • 上海博物館。
  • 靜安嘉里中心、陸家嘴商場。
  • 武康路、愚園路周邊咖啡廳。
  • 上海中心或陸家嘴室內空間。
  • 飯店或民宿休息。
